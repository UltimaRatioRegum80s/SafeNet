you did the right check—clusterLayers = 50, but clusterEls = 0.
That means: the cluster group has 50 markers internally, but no cluster icons were drawn into the DOM for your current view. Two most likely reasons (often both on mobile):

Map view never refreshes after layers are added (mobile timing; cluster doesn’t render icons until a proper moveend/size).

You’re centered away from the incidents (so nothing is in the viewport; with removeOutsideVisibleBounds the plugin won’t draw off-screen icons).

Let’s fix both at once, behind the existing flag so desktop stays untouched.

@Replit — copy/paste patch (flag-gated, progress-safe)

File: client/src/components/MapView.tsx

Add this helper near the top (after imports):

import { Flags } from "@/lib/flags";
import { isMobileLike } from "@/lib/platform";

// Ensure mobile cluster renders & the map centers on data (flag only)
function postAddMobileRefresh(map: L.Map, cluster: L.MarkerClusterGroup) {
  if (!Flags.fixMobileMarkers || !isMobileLike) return;

  // 1) Ensure Leaflet knows container size (mobile layout often changes)
  map.invalidateSize();

  // 2) Ask MarkerCluster to (re)draw icons now
  (cluster as any).refreshClusters?.();

  // 3) If the current view doesn't intersect data, fit to data bounds
  const b = cluster.getBounds();
  if (b && b.isValid()) {
    const intersects = map.getBounds().intersects(b);
    if (!intersects) {
      map.fitBounds(b.pad(0.2), { animate: false });
    }
  }
}

Where to call it (two places)

Right after you attach the cluster to the map (flag already used here):

if (Flags.fixMobileMarkers && isMobileLike && mapRef.current && clusterRef.current) {

Why this will work

Your latest output shows the data is loaded (clusterLayers: 50) but no cluster icons are in the DOM (clusterEls: 0). That happens when mobile adds layers before the map is fully sized/settled or when the initial view doesn’t intersect your data bounds. The patch explicitly:

invalidates size (so Leaflet can compute positions),

refreshes the cluster (forces icon generation),

fits to data when the view is off the incidents.

All of it is flag-gated — desktop remains exactly as-is and you can turn it off instantly with ?NN_FIX_MOBILE_MARKERS=0.
