3) Robust refine handshake (return path)

Right now we fire nn:begin-location-pick. Let’s also listen for a nn:location-picked with {lat,lng} so the panel updates even if it’s reopened later:

// ReportPanel.tsx
useEffect(() => {
  const handler = (e: Event) => {
    const detail = (e as CustomEvent<{lat:number;lng:number}>).detail;
    if (detail && setRefinedCoords) setRefinedCoords(detail);
  };
  window.addEventListener("nn:location-picked", handler as EventListener);
  return () => window.removeEventListener("nn:location-picked", handler as EventListener);
}, [setRefinedCoords]);


And in your Map page, when the user confirms the pin:

window.dispatchEvent(new CustomEvent("nn:location-picked", { detail: { lat, lng } }));

6) Optimistic update (map/feed feel instant)

Use a tiny incidents store so UI updates immediately; socket confirm will reconcile.

// client/src/store/incidentsStore.ts
import { create } from "zustand";
type Incident = { id: string; type: string; status: "pending"; lat?:number; lng?:number; createdAt:string; /* ... */ };
export const useIncidents = create<{items:Incident[]; add:(i:Incident)=>void; reconcile:(id:string, i:Incident)=>void}>((set) => ({
  items: [],
  add: (i) => set((s) => ({ items: [i, ...s.items] })),
  reconcile: (id, next) => set((s) => ({ items: s.items.map(x => x.id === id ? next : x) })),
}));


In ReportPanel submit:

const tempId = `temp-${crypto.randomUUID()}`;
useIncidents.getState().add({
  id: tempId, type: selected.id, status: "pending", lat: chosenCoords?.lat, lng: chosenCoords?.lng, createdAt: new Date().toISOString(),
});


Socket listener (Map/Feed bootstrap):

socket.on("incident:created", (incident) => {
  const { reconcile, add } = useIncidents.getState();
  // replace temp if matches nearby fields; else just add
  const temp = useIncidents.getState().items.find(i => i.id.startsWith("temp-") && i.type === incident.type);
  temp ? reconcile(temp.id, incident) : add(incident);
});
