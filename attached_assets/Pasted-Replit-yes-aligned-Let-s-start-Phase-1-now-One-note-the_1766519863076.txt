PHASE 1: Radius/time-based feed query (no room dependency)

A) Define feed parameters
- Inputs:
  - center_lat, center_lng (device location or user home pin fallback)
  - radius_km (default 5km; allow 1/3/5/10)
  - time_window_hours (default 72h; allow 24h/72h/7d)
  - optional: severity, category
- Output: incidents sorted by created_at desc (or distance asc then created_at desc)

B) Backend endpoint
Create:
GET /api/incidents/nearby?lat=...&lng=...&radiusKm=...&hours=...&severity=...&category=...

C) Query logic (beta-safe + accurate)
1) Time filter:
- created_at >= now() - interval '{hours} hours'

2) Bounding box prefilter (fast)
Compute:
- lat_delta = radius_km / 111.32
- lng_delta = radius_km / (111.32 * cos(radians(center_lat)))

SQL prefilter:
- latitude BETWEEN center_lat - lat_delta AND center_lat + lat_delta
- longitude BETWEEN center_lng - lng_delta AND center_lng + lng_delta

3) Distance filter (haversine)
- Filter using haversine in SQL or in code after prefilter.
- Return only incidents with distance <= radius_km.
