Since flag=ON and we still see no markers/clusters on mobile, the most likely thing is: the gated path didn’t run (we’re still creating L.circleMarker, which markercluster ignores). That can happen if our isLikelyMobile check is false in your test environment/PWA shell.

Here’s a tight, non-destructive verify → fix plan that keeps Progress Law intact.

Verify (console only, no edits)

Run these with ?NN_FIX_MOBILE_MARKERS=1 after the map loads:

Interpretation

If divIcons = 0 and isMarker=false / isCircle=true, we’re still hitting the circleMarker branch ⇒ the mobile gate blocked the fix.

If layers > 0 and isMarker=true, but .marker-cluster = 0, check if the MarkerCluster CSS is loaded:

[...document.styleSheets].some(s => {
  try { return [...(s.cssRules||[])].some(r => (r.selectorText||'').includes('.marker-cluster')); }
  catch { return false; } // cross-origin CSS
})

Surgical code tweak (safe & reversible)

Goal: make the fallback run whenever getIncidentIcon(...) returns null — regardless of UA — but only when the flag is ON. This keeps desktop unchanged (desktop has icons) and ensures mobile (or any environment with broken icons) gets a cluster-compatible L.Marker.

In the file with addIncidentToCluster:

// BEFORE (gated by isLikelyMobile)
} else if (Flags.fixMobileMarkers && isLikelyMobile) {
  layer = L.marker(ll, { icon: buildFallbackDivIcon({ size: 14, color: '#2563eb' }), title: inc.title ?? inc.type });
} else {
  layer = L.circleMarker(ll, { radius: 7, color: '#2563eb' });
}

// AFTER (gated only by the flag + icon === null)
} else if (Flags.fixMobileMarkers) {
  layer = L.marker(ll, { icon: buildFallbackDivIcon({ size: 14, color: '#2563eb' }), title: inc.title ?? inc.type });
} else {
  layer = L.circleMarker(ll, { radius: 7, color: '#2563eb' });
}


Nothing else changes:

Desktop path (when icons load) = identical.

If desktop ever failed to load icons, you’d still get markers (divIcon) instead of disappearing — which is safer.

If clusters appear, ensure the CSS is imported in your bundle for the PWA route.
