✅ Part 2 — “Get the App” PWA Install Button
Objective

Expose native PWA installation capability safely and minimally.

Implementation Requirements
1️⃣ Capture beforeinstallprompt

In root component (App.tsx or equivalent):

Listen for beforeinstallprompt

Call preventDefault()

Store event in state

Set installAvailable = true

Must be React state-based (not global variable only).

2️⃣ Show “Get the App” Button Only When:

installAvailable === true

App is NOT already installed (display-mode: standalone false)

If installed → hide button completely.

3️⃣ On Click:

Call deferredPrompt.prompt()

Await userChoice

Clear stored prompt

Set installAvailable = false

4️⃣ iOS Safari Handling

Because iOS does not support beforeinstallprompt:

If:

iOS detected

NOT standalone

No installAvailable event

Then:

Show “Get the App” button → opens small modal:

To install:
Tap Share → Add to Home Screen

Keep modal minimal. No styling theatrics.
