Tiny hardening patches (copy-paste)

Debounce selection pans (avoid spamming if user taps multiple rows quickly):

let panT: any;
function centerTo(map: L.Map, lat: number, lng: number, minZoom = 15) {
  clearTimeout(panT);
  panT = setTimeout(() => {
    map.setView([lat, lng], Math.max(minZoom, map.getZoom()), { animate: true });
  }, 60);
}


Passive listeners on map overlays (keep panning smooth):

/* Any overlay wrapper above the map */
.overlay-events-none { pointer-events: none; }
.overlay-events-auto { pointer-events: auto; } /* for buttons only */
