2) Enhance your marker helper to render badges

Patch your existing Leaflet helper so it can style markers when optimistic/offline is true.

client/src/features/map/createIncidentMarker.ts (adjust signature/HTML)

import L from "leaflet";
import { INCIDENT_MARKERS } from "@/features/report/incidentTypes";

// Registry (optional but useful for updates)
const markerRegistry = new Map<string, L.Marker>();

type CreateMarkerOpts = {
  id: string;
  type: string;
  lat: number;
  lng: number;
  description?: string;
  optimistic?: boolean;
  offline?: boolean;
  map?: L.Map; // if not injected elsewhere
};

export function createIncidentMarker({
  id, type, lat, lng, description, optimistic, offline, map,
}: CreateMarkerOpts): L.Marker {
  const iconUrl = INCIDENT_MARKERS[type as keyof typeof INCIDENT_MARKERS]?.icon;
  const classes = ["nn-marker"];
  if (optimistic) classes.push("nn-marker--optimistic");
  if (offline) classes.push("nn-marker--offline");

  const badgeText = offline ? "⏳" : optimistic ? "⚡" : "";

  const html = `
    <div class="${classes.join(" ")}" data-id="${id}">
      <img class="nn-marker__img" src="${iconUrl}" alt="${type}" />
      ${badgeText ? `<span class="nn-marker__badge">${badgeText}</span>` : ""}
    </div>
  `;

  const divIcon = L.divIcon({
    html,
    className: "",           // keep empty so our classes control styles
    iconSize: [36, 36],
    iconAnchor: [18, 36],
    popupAnchor: [0, -28],
  });

  const marker = L.marker([lat, lng], { icon: divIcon });
  if (description) marker.bindPopup(description);

  // add to map now or return for caller to add
  if (map) marker.addTo(map);

  markerRegistry.set(id, marker);
  return marker;
}

/** update flags on an existing marker (swap classes + badge) */
export function updateMarkerFlags(
  id: string,
  { optimistic, offline }: { optimistic?: boolean; offline?: boolean }
) {
  const marker = markerRegistry.get(id);
  if (!marker) return;
  const el = (marker as any)._icon as HTMLElement | null;
  if (!el) return;

  el.classList.toggle("nn-marker--optimistic", !!optimistic);
  el.classList.toggle("nn-marker--offline", !!offline);

  let badge = el.querySelector(".nn-marker__badge") as HTMLSpanElement | null;
  const wantBadge = offline || optimistic;
  if (wantBadge && !badge) {
    badge = document.createElement("span");
    badge.className = "nn-marker__badge";
    el.appendChild(badge);
  }
  if (!wantBadge && badge) {
    badge.remove();
  } else if (badge) {
    badge.textContent = offline ? "⏳" : optimistic ? "⚡" : "";
  }
}

/** replace temp ID with real ID in registry (after server confirms) */
export function replaceMarkerId(tempId: string, newId: string) {
  const marker = markerRegistry.get(tempId);
  if (!marker) return;
  markerRegistry.delete(tempId);
  markerRegistry.set(newId, marker);

  const el = (marker as any)._icon as HTMLElement | null;
  if (el) el.setAttribute("data-id", newId);
}


if you already have a registry, merge the two tiny helpers into it.

3) Wire flags when adding markers
A) Optimistic: you’re already adding a temp incident in QuickReportCard. Pass the flag through to the marker creation (wherever you render markers from store/hydration).

If you add markers directly on submission (common pattern), just call:

createIncidentMarker({
  id: tempId,
  type,
  lat, lng,
  description: note?.trim() || undefined,
  optimistic: true,
  map, // your Leaflet map instance
});


If your map builds markers from store/React Query:

include optimistic?: boolean and offline?: boolean in the incident model,

pass them into createIncidentMarker during render.

B) After server confirms, clear optimistic flag and replace ID

Where you previously did:

updateIncidentId(tempId, result.id);


also update the marker UI:

import { updateMarkerFlags, replaceMarkerId } from "@/features/map/createIncidentMarker";

replaceMarkerId(tempId, result.id);
updateMarkerFlags(result.id, { optimistic: false, offline: false });

C) Offline queued path (if you choose to show a queued marker)

When you enqueue (offline), also drop a marker with the offline style:

const tempId = `offline-${Date.now()}`;
createIncidentMarker({
  id: tempId,
  type,
  lat, lng,
  description: note?.trim() || undefined,
  offline: true,
  map,
});


Then, when the queue flushes and server returns a real id, call:

replaceMarkerId(tempId, realId);
updateMarkerFlags(realId, { offline: false });


If you prefer not to show offline markers until back online, skip this; the CSS/JS supports it whenever you enable it.
