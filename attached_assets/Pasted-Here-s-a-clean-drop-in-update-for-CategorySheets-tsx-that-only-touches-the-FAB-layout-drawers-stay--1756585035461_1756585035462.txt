1) Update SeverityFab to accept className (remove inline style)
// replace the SeverityFab signature + return with this version
function SeverityFab({
  severity,
  label,
  onClick,
  className,
}: {
  severity: Severity;
  label: string;
  onClick: () => void;
  className?: string;
}) {
  const icon =
    severity === "low" ? <Circle className="h-5 w-5" /> :
    severity === "medium" ? <AlertTriangle className="h-5 w-5" /> :
    <Flame className="h-5 w-5" />;

  return (
    <button
      onClick={onClick}
      aria-label={`Report a ${label.toLowerCase()}-risk incident`}
      className={clsx(
        "nn-glass backdrop-blur-md",
        FAB_STYLE,           // padding, ring, press animation, focus styles
        COLORS[severity],    // ✅ brings back the colors
        className            // for placement from parent
      )}
    >
      {icon}
      <span className="font-semibold">{label}</span>
    </button>
  );
}

Buttons are now in the middle of the screen, horizontal, and the row’s container is 2/3 screen width (w-2/3), capped by max-w-md with a minimum for tiny phones.

Colors are restored via COLORS[severity].

If you prefer the trio to be centered horizontally but slightly below the exact middle, change top-1/2 -translate-y-1/2 to something like top-[58%] -translate-y-1/2 or top-[60%].
