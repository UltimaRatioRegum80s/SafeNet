Pressing a button will:

track("severity_sheet_open", { severity })

haptic vibrate(8)

openSheet(severity) (your existing drawer/sheet that shows the incident grid)

Drawer grid already filters by store severity; if it doesn’t in one place, we’ll wire it (1-liner).

Tablet: same buttons, left-aligned instead of centered.

A11y: proper focus rings + keyboardable buttons.

No draft store, no route changes.

Why this way

Zero changes to ReportPanel, URL semantics, or type-driven severity.

Only replaces UI for the “entry” interaction; everything else continues to work.

1) New component: SeveritySelect (vertical buttons)

src/components/SeveritySelect.tsx

import clsx from "clsx";

export type Severity = "low" | "medium" | "high" | "critical";

type Props = {
  onSelect: (v: Severity) => void;   // you’ll pass openSheet+store here
  className?: string;
};

const baseBtn =
  "h-14 w-full rounded-full font-semibold text-base transition-colors shadow-sm " +
  "bg-slate-200/90 text-slate-900 " +
  "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-950";

export function SeveritySelect({ onSelect, className }: Props) {
  const click = (v: Severity) => {
    try { (window as any).track?.("severity_sheet_open", { severity: v }); } catch {}
    if (navigator.vibrate) navigator.vibrate(8);
    onSelect(v);
  };

  return (
    <div
      className={clsx("w-full max-w-sm space-y-4", className)}
      role="group"
      aria-label="Choose incident severity"
    >
      <button className={clsx(baseBtn, "ring-2 ring-yellow-400")} onClick={() => click("low")}>
        Low
      </button>

      <button className={clsx(baseBtn, "ring-2 ring-amber-600")} onClick={() => click("medium")}>
        Medium
      </button>

      <button className={clsx(baseBtn, "ring-2 ring-red-500")} onClick={() => click("high")}>
        High
      </button>

      <button
        className={clsx(
          "h-14 w-full rounded-full font-semibold text-base transition-colors shadow-md",
          "bg-red-800 text-white",
          "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-red-400 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-950"
        )}
        onClick={() => click("critical")}
      >
        Critical
      </button>
    </div>
  );
}

export default SeveritySelect;


Matches your mock: neutral fill + colored ring; Critical is solid.

Strong, WCAG-friendly focus rings on dark backgrounds.
