1) Ensure cluster is attached exactly once (idempotent)

Add this right after map and cluster are created (keep behind the flag):

// attach cluster to map once (flag only)
if (Flags.fixMobileMarkers && mapRef.current && clusterRef.current) {
  if (!mapRef.current.hasLayer(clusterRef.current)) {
    mapRef.current.addLayer(clusterRef.current);
  }
  (window as any)._map = mapRef.current;      // debug only (flagged)
  (window as any)._cluster = clusterRef.current; // debug only (flagged)
}

2) Stop the Leaflet zoom crash (defensive guard)

Monkey-patch only when the flag is ON so desktop is unaffected:

// defensive guard: ignore marker zoom anim if marker is not on a map
if (Flags.fixMobileMarkers && (L as any).Marker && !(L as any).Marker.__nnPatched) {
  const P = (L as any).Marker.prototype as any;
  const original = P._animateZoom;
  P._animateZoom = function(e: any) {
    if (!this._map) return;     // <- prevents "_latLngToNewLayerPoint" on null
    return original.call(this, e);
  };
  (L as any).Marker.__nnPatched = true;
}

3) (Optional but safer) Disable marker zoom animation on the flagged path

When you create the map, pass these options only if the flag is ON:

const map = L.map(container, {
  // ...your existing options
  zoomAnimation: !Flags.fixMobileMarkers,        // disable when flag = ON
  markerZoomAnimation: !Flags.fixMobileMarkers,  // ditto
  fadeAnimation: !Flags.fixMobileMarkers,
});


If the map is already constructed elsewhere, you can do a light override after init:

if (Flags.fixMobileMarkers && mapRef.current) {
  (mapRef.current as any).options.zoomAnimation = false;
  (mapRef.current as any).options.markerZoomAnimation = false;
  (mapRef.current as any).options.fadeAnimation = false;
}
