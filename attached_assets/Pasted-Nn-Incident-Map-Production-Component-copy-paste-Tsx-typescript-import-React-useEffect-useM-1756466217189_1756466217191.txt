function emptyFC(): GeoJSON.FeatureCollection {

function toFeatureCollection(rows: Incident[]): GeoJSON.FeatureCollection<
  GeoJSON.Point,
  any
> {
  return {
    type: "FeatureCollection",
    features: rows.map((i) => ({
      type: "Feature",
      properties: { id: i.id, severity: i.severity, title: i.title },
      geometry: { type: "Point", coordinates: [i.lng, i.lat] },
    })),
  };
}

NN Incident Map – Production Component (copy-paste TSX)

It implements all the changes we discussed:

full-screen MapLibre map (map-first)

floating zoom / recenter + filter FAB

draggable bottom sheet (peek / half / full) with severity chips

Quick install
npm i maplibre-gl framer-motion lucide-react @tanstack/react-query

Hook it up (minimal)

Wrap your app once with React Query:

// main.tsx or App.tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
const qc = new QueryClient();
export default function AppRoot() {
  return (
    <QueryClientProvider client={qc}>
      <App />
    </QueryClientProvider>
  );
}


Render the map screen:

// e.g. src/pages/IncidentMap.tsx
import NNIncidentMap from '@/components/NNIncidentMap';
export default function IncidentMapPage() {
  return <NNIncidentMap />;
}


Point the component’s API_URL constant to your NN incidents endpoint (it expects an array of:

{ id, title, description?, severity: 'low'|'medium'|'high'|'emergency', lng, lat, createdAt }
