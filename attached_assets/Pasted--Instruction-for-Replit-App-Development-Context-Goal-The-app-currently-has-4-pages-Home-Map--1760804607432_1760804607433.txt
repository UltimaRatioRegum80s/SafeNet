In mobile view, only the Map page currently has a modern design with a Floating Navigation Bar (top-centered, card-style navigation with rounded corners and subtle elevation).

I want all pages (Home, Map, Report, Feed) to include this same Floating Navigation Bar at the top of the page, with identical styling, layout, and behavior as on the Map page.

Suggested Safe Refactor Steps

Create a Shared Component

File: src/components/FloatingNav.tsx

Contains the same floating bar logic as used in the Map page.

Exports a reusable <FloatingNav /> component.

Integrate into Pages Carefully

For each of Home.tsx, Report.tsx, and Feed.tsx:
Add:

import FloatingNav from "@/components/FloatingNav";


Then, inside the top-level JSX container:

<div className="relative h-screen">
  <FloatingNav />
  {/* existing content */}
</div>


Keep all existing logic, hooks, and layouts intact.

Restrict to Mobile View

Wrap <FloatingNav /> with:

<div className="block md:hidden">
  <FloatingNav />
</div>


to prevent interference with desktop layouts.

Manual Verification

Test all navigation links for correct routing and state persistence.

Verify appearance across mobile devices and browser developer tools.

Ensure that the Map page behavior remains unchanged.
