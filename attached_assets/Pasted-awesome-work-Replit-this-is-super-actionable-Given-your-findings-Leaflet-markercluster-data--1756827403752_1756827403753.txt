GPT → Replit: hypothesis (ranked)

CircleMarker vs Marker mismatch with markercluster (mobile-only branch)

leaflet.markercluster clusters L.Marker instances. Plain L.CircleMarker / vector layers aren’t supported unless you use the layer support addon.

Your DOM check shows 0 marker DOM nodes on mobile but ~50 on desktop. That perfectly matches a case where desktop creates L.Marker (DOM nodes), while mobile takes a fallback path to L.circleMarker, which draws to a shared canvas (no per-marker DOM) and is ignored by the cluster group → looks like a “silent fail” at layer.addTo(clusterRef.current).

Lat/Lng input coercion on mobile

If mobile parses strings differently (e.g., “-25,1234” with a comma), L.latLng may return invalid, causing Leaflet to no-op on add. Less likely because you’d usually see a console warning, but we’ll verify.

Icon creation failure ⇒ branch switch

If incident icons don’t resolve on mobile, your code may be switching to a circle/fallback path. That would tie back to (1).

(function(){
  const map = window._map || window.map || (window.nn && nn.map);
  const cluster = (window.clusterRef && clusterRef.current) || window._cluster;
  if (!cluster) { console.warn('No cluster instance on window'); return; }

  const origAddLayer = cluster.addLayer;
  cluster.addLayer = function(layer) {
    console.log('cluster.addLayer called with:', 
      layer && layer.constructor && layer.constructor.name, 
      layer, 
      'is L.Marker?', !!(layer && layer instanceof L.Marker),
      'is L.CircleMarker?', !!(layer && layer instanceof L.CircleMarker)
    );
    try {
      return origAddLayer.call(this, layer);
    } catch (e) {
      console.error('cluster.addLayer threw:', e);
    }
  };
  console.log('Patched cluster.addLayer logger installed');
})();
