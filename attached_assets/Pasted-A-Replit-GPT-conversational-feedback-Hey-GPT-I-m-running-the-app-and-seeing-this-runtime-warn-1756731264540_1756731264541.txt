1) Safe wrapper utility (reusable)

Create src/components/MaybeWrapper.tsx to handle the “Fragment unless we need attributes” case. If any props other than children/className exist, it renders a div and passes them through (data- attributes included). Otherwise, it renders a Fragment to avoid extra DOM.

// src/components/MaybeWrapper.tsx
import React from "react";

type MaybeWrapperProps = React.PropsWithChildren<
  React.HTMLAttributes<HTMLDivElement>
>;

/**
 * Renders a Fragment when there are no extra attributes to attach.
 * Falls back to a <div> when props (e.g., data-*, id, style) must be forwarded.
 */
export const MaybeWrapper: React.FC<MaybeWrapperProps> = ({
  children,
  className,
  ...rest
}) => {
  // Determine if there are any attributes worth forwarding.
  const hasForwardableAttrs = Object.keys(rest).length > 0 || !!className;

  return hasForwardableAttrs ? (
    <div className={className} {...rest}>
      {children}
    </div>
  ) : (
    <>{children}</>
  );
};


If you truly want no extra box when a <div> is used, you can add className="contents" where you use MaybeWrapper. Tailwind’s contents makes the element boxless while still legal for attributes.
