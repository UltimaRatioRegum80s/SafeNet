A) layout skeleton (map as background)

Put this structure around your map container (Map.tsx). Keep your existing Leaflet init; just wrap layers.

  {/* MAP = background */}
  <div id="leaflet-map" ref={mapEl} className="absolute inset-0 z-0" />

  {/* UI LAYER (floats above map) */}
  <div className="absolute inset-0 z-20 pointer-events-none">
    {/* Header overlay */}
    <div className="absolute top-0 inset-x-0">
      <div className="h-20 bg-gradient-to-b from-black/50 to-transparent" />
      <div className="px-3 pt-3">
        <div

        >
          <span className="font-semibold">Incident Map</span>

B) tiny CSS tokens (glassy FABs + overlays)

Add to your global CSS (or Tailwind @apply if you prefer):

/* glassy floating action button */
.nn-fab{
  @apply rounded-full w-12 h-12 grid place-items-center
         bg-white/90 text-slate-900 shadow-lg active:scale-95;
}
/* translucent “card over map” look */
.nn-glass{
  @apply bg-white/10 border border-white/10 backdrop-blur;
}


Use nn-glass for any floating mini menu, popover, or the sheet header.

D) pointer-events ergonomics

To keep the map easy to drag:

parent overlay div → pointer-events-none

only buttons/interactive elements → pointer-events-auto (as shown above)

E) slim the header on small screens

Hide the big page header on mobile if you still render it above the map:

{/* top bar above the map */}
<div className="hidden md:block">{/* existing desktop header */}</div>
