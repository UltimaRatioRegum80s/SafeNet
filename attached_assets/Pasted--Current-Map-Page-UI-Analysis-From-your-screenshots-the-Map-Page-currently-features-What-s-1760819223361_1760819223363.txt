⚠️ Areas for Improvement
Issue	Description	Impact
1. Floating stack looks “bolted on”	The current vertical stack of buttons (zoom, GPS, layer) looks functional but not polished. It lacks the modern “floating surface” or “control panel” treatment.	Visual imbalance; breaks immersion.
2. No contextual feedback	The GPS center button doesn’t visually indicate active state (e.g., tracking enabled vs manual pan).	Users can’t tell if the map is following them.
3. Button affordance	Icons are slightly small, spacing is tight, and no haptic or animation feedback.	Slightly reduces perceived quality.
4. Layer button lacks hierarchy	The layer switch feels like an equal-level action, but it’s secondary.	Confuses prioritization of actions.
5. Style contrast (especially in light mode)	On light map tiles, button backgrounds and shadows are less visible.	Slightly reduced contrast / discoverability.
🎯 Improvement Goals

Replace the floating right-side button stack with a compact, glassy side drawer / control panel.

Introduce animated feedback for active buttons (especially GPS center).

Use new iconography for clarity and style consistency.

Maintain non-obstructive visibility — controls should float elegantly above the map, not block content.

Preserve full functionality — zoom, recenter, layer toggle — with no behavior change.

🧩 Implementation Suggestion for Replit (Suggestion Only)

⚠️ This is a visual/UI enhancement suggestion only — all existing map logic and event handlers remain untouched.

1. Create MapControlPanel.tsx
import { Plus, Minus, Crosshair, Layers } from "lucide-react";
import { motion } from "framer-motion";
import { cn } from "@/lib/utils";
import { useState } from "react";

interface Props {
  onZoomIn: () => void;
  onZoomOut: () => void;
  onCenter: () => void;
  onToggleLayer: () => void;
  gpsActive?: boolean;
}

export default function MapControlPanel({
  onZoomIn,
  onZoomOut,
  onCenter,
  onToggleLayer,
  gpsActive,
}: Props) {
  const [open, setOpen] = useState(true);

  return (
    <motion.div
      initial={{ x: 80, opacity: 0 }}
      animate={{ x: open ? 0 : 80, opacity: open ? 1 : 0 }}
      transition={{ duration: 0.3, ease: "easeOut" }}
      className={cn(
        "fixed right-3 top-1/3 z-50 flex flex-col gap-2 p-2 rounded-2xl",
        "bg-neutral-900/60 dark:bg-neutral-100/30 backdrop-blur-md",
        "shadow-[0_8px_20px_-8px_rgba(0,0,0,0.5)] border border-white/10"
      )}
    >
      <button
        onClick={onZoomIn}
        className="h-10 w-10 flex items-center justify-center rounded-full bg-neutral-800/70 hover:bg-neutral-700/70 transition"
      >
        <Plus size={18} className="text-white" />
      </button>

      <button
        onClick={onZoomOut}
        className="h-10 w-10 flex items-center justify-center rounded-full bg-neutral-800/70 hover:bg-neutral-700/70 transition"
      >
        <Minus size={18} className="text-white" />
      </button>

      <button
        onClick={onCenter}
        className={cn(
          "h-10 w-10 flex items-center justify-center rounded-full bg-neutral-800/70 transition",
          gpsActive ? "ring-2 ring-blue-400/70" : "hover:bg-neutral-700/70"
        )}
      >
        <Crosshair size={18} className="text-white" />
      </button>

      <button
        onClick={onToggleLayer}
        className="h-10 w-10 flex items-center justify-center rounded-full bg-neutral-800/70 hover:bg-neutral-700/70 transition"
      >
        <Layers size={18} className="text-white" />
      </button>
    </motion.div>
  );
}
