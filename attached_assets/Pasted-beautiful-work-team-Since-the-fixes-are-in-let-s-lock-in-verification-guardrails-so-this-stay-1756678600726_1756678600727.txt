1) Protect against hidden-container mount (tabs/modals)

If the map lives inside a tab that can start hidden, fire an explicit size invalidation when it becomes visible.

// call this when the map's parent panel becomes visible (e.g. after tab change)
export function onMapPanelShown() {
  const el = document.getElementById("nn-map");
  // small async to let layout settle
  setTimeout(() => {
    // @ts-ignore potential null guarded
    el && (el.dispatchEvent(new Event("resize")));
  }, 0);
}


Trigger onMapPanelShown() in your tab/view switch handler. Our existing listeners (resize/orientation/ResizeObserver) will catch this synthetic resize and run invalidateSize().

2) Guard against excessive cluster rebuilds (perf win on mobile)

If React Query invalidates frequently, we can skip full rebuilds unless the set meaningfully changed.

// in InteractiveMap.tsx, before clearLayers(), quick equality check
const keyOf = (i: Incident) => `${i.id}-${i.lat}-${i.lng}-${i.type}`;
const prevKeyRef = useRef<string>("");

const currentKey = incidents.map(keyOf).join("|");
if (prevKeyRef.current === currentKey) {
  // nothing meaningful changed; avoid churn
  return null;
}
prevKeyRef.current = currentKey;

// proceed with cluster.clearLayers() & re-add


Small but helps on low-end Androids.

4) Server-side: light telemetry to spot mobile-only issues

Add minimal logging around POST and socket emits (strip PII):

// server/middleware/telemetry.ts
export function logIncidentCreate(req, res, next) {
  const started = Date.now();
  res.on("finish", () => {
    if (req.path === "/api/incidents" && req.method === "POST") {
      console.log("[INCIDENT_CREATE]", {
        status: res.statusCode,
        ms: Date.now() - started,
        uaMobile: /Mobile|Android|iPhone|iPad/i.test(req.headers["user-agent"] || ""),
      });
    }
  });
  next();
}


Wire once in your server bootstrap:

app.use(logIncidentCreate);


This’ll quickly tell us if mobile POSTs are slower/failing.

5) Quick regression tests (schema + normalization)
// shared/__tests__/schema.incident.test.ts
import { insertIncidentSchema, normalizeIncidentCoords } from "../schema";

test("coerces string lat/lng", () => {
  const p = insertIncidentSchema.parse({ title:"t", description:"d", lat:"-33.9", lng:"18.4", type:"fire" });
  expect(typeof p.lat).toBe("number");
});

test("swaps reversed coords", () => {
  const n = normalizeIncidentCoords({ lat: 120, lng: -33 }); // obviously swapped
  expect(Math.abs(n.lat) <= 90).toBe(true);
  expect(Math.abs(n.lng) <= 180).toBe(true);
});

test("rounds precision", () => {
  const n = normalizeIncidentCoords({ lat: -33.912345678, lng: 18.412345678 });
  expect(n.lat.toString().split(".")[1].length).toBeLessThanOrEqual(6);
});
