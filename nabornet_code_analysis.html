The frontend is built using Vite as the build tool, providing fast development and optimized production builds. State management is handled through Zustand for global application state, with React Query managing data fetching and caching. The UI is constructed using shadcn/ui components built on top of Radix UI primitives, styled with Tailwind CSS for consistent design. Navigation is managed through Wouter, a lightweight routing solution. ### Backend Architecture The backend leverages Firebase as a Backend-as-a-Service solution, providing a serverless architecture. Firebase Authentication handles user management with support for email/password and magic link authentication. Cloud Firestore serves as the primary database with real-time synchronization capabilities. Cloud Functions handle server-side business logic, data validation, and automated processes. The architecture implements strict multi-tenant data isolation using tenantId fields across all collections. ### Database Design The Firestore database follows a flat collection structure optimized for multi-tenancy: - `tenants`: Organization metadata and billing information - `users`: User profiles with role-based permissions and tenant associations - `sites`: Location definitions with geofencing capabilities - `patrolPoints`: GPS coordinates and QR code assignments for guard check-ins - `routes`: Predefined patrol sequences linking multiple patrol points - `shifts`: Guard scheduling and assignment tracking - `checkins`: Real-time patrol verification with GPS and QR validation - `incidents`: Issue reporting with photo attachments and workflow status - `alerts`: Emergency SOS notifications with location tracking ### Authentication and Authorization The system implements role-based access control (RBAC) with four distinct user roles: - **Guard**: Mobile-focused interface for patrol check-ins and incident reporting - **Supervisor**: Management dashboard for monitoring guard activities and incidents - **Client**: Read-only access to reports and site statistics - **Admin**: Full system administration including tenant and user management Custom Firebase claims enforce role-based permissions at the database level, with Firestore security rules providing defense-in-depth access control. ### Progressive Web App Features The application is designed as an installable PWA with offline capabilities for critical guard functions. Service workers cache essential resources and enable offline check-ins, which sync automatically when connectivity is restored. Push notifications keep supervisors informed of incidents and emergency alerts in real-time. ### Maps Integration The platform integrates MapLibre for open-source mapping with automatic fallback to Google Maps when API keys are available. This provides flexible deployment options while maintaining consistent geolocation features across guard tracking, geofencing, and incident reporting. ## External Dependencies ### Firebase Services - **Firebase Authentication**: User management with email/password and passwordless magic link authentication - **Cloud Firestore**: Real-time NoSQL database with offline synchronization - **Cloud Functions**: Serverless functions for business logic, data validation, and automated workflows - **Firebase Storage**: File storage for incident photos and QR code images - **Firebase Cloud Messaging**: Push notifications for real-time alerts and updates - **Firebase Hosting**: Static site hosting with automatic SSL and CDN distribution ### Third-Party Libraries - **MapLibre**: Open-source mapping solution for geolocation features - **Google Maps API**: Optional premium mapping service with enhanced features - **Radix UI**: Accessible component primitives for UI construction - **React Query**: Server state management and data synchronization - **Zustand**: Lightweight state management for client-side application state - **QR Code Generation**: Server-side QR code creation for patrol point identification - **Canvas API**: Image processing for QR code generation and photo manipulation ### Development Tools - **Vite**: Fast build tool with hot module replacement - **TypeScript**: Type safety and developer experience enhancement - **Tailwind CSS**: Utility-first CSS framework for consistent styling - **ESLint/Prettier**: Code quality and formatting standards - **Drizzle**: Database schema definition and migration tooling (prepared for potential PostgreSQL migration)
